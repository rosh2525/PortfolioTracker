# PortfolioTracker frontend

The Next.js frontend for PortfolioTracker, a self-hosted portfolio and investment tracking application.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The main application code lives in `src/app`, with reusable components in `src/components`.
