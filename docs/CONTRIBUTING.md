# Contributing

Create a focused branch from `main`, keep user-facing text translatable, and include tests for behavior changes. Before opening a pull request, run the backend Ruff and Django checks plus the frontend tests, type check, lint, and production build.

Use conventional commit messages such as `feat:`, `fix:`, `docs:`, and `chore:`. Never commit `.env` files, credentials, database data, build output, or dependency directories.
